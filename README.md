# RFT Utazási Költségkalkulátor

## A projekt célja
Ez az alkalmazás a Rendszerfejlesztés technológiája kurzus 3 fős csapatprojektje. Célja, hogy egy egyszerű konzolos felületen keresztül nyilvántartsa az egyetemi bejárás (Hajdúszoboszló, Hajdúnánás, Nyíradony -> Nyíregyháza) utazási adatait.

## Célközönség és funkciók
A programot a csapattagok (Zoli, Krisztina, Pisti) használják a napi egyetemi utazásaik rögzítésére. Az alkalmazás a beépített fix paraméterek (távolság, járművek átlagfogyasztása, buszjegy ára) alapján automatikusan összesíti és táblázatos formában megjeleníti az utazási költségeket.
