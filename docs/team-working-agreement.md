# Csapatszerződés és Munkafolyamat

## Kommunikáció
* A csapat elsődleges kommunikációs csatornája: Messenger csoport.
* Ha valaki elakad egy feladattal, legkésőbb 1 napon belül jelzi a többieknek.

## Munkafolyamat és Definition of Done (DoD)
Egy feladat (Issue) akkor tekinthető késznek (Done), ha:
* A kód elkészült és hiba nélkül lefut.
* A változtatásokat feltöltöttük (pusholtuk) a közös GitHub repository-ba.
* A Kanban (Project) táblán a feladat kártyáját áthúztuk a "Done" oszlopba.
